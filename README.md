# Lejdaeron

A browser tower defense in the style of Warcraft III custom maps. **Playtest build.**

Play: https://davis-saas.github.io/lejdaeron/

- Classic Defense: build towers beside the road and hold the castle for 28 levels.
- Coming next: Line Tower Wars against the computer, then online play with friends.

Controls: A / S / E build Archer, Sharp or Elemental towers (Shift keeps building), Q W E R T upgrade the selected tower, X sells, N calls the next level, P pauses, 1 2 3 set the speed.

Credits: rules, towers and creeps come from the Warcraft III custom map Line Tower Wars 45 by Loss05, Nob, Trymio and t3tr1s. This is a fan project, not affiliated with or endorsed by Blizzard Entertainment. All art is original, modelled and rendered in Blender.
